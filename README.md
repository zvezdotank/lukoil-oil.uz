# lukoil-oil.uz

Сайт официального дистрибьютора смазочных материалов ЛУКОЙЛ в Республике Узбекистан.
Статика, без зависимостей и сборщиков, хостинг — GitHub Pages.

**Задача сайта:** конвертировать входящий трафик в звонок или письмо на почту.

## Структура

```
build.py        сборщик страниц (шаблоны + разметка)
content.py      весь текст и данные каталога — правится отдельно от вёрстки
site.css        дизайн-система: нулевые радиусы, толстые правила, красный #ec3013
site.js         меню, модалка обратного звонка, подбор по технике, отправка заявок
fonts/          Golos Text, self-hosted woff2 (кириллица + латиница), 60 КБ
img/            фотографии в webp + jpg-фолбэк
```

Сгенерированные файлы (`*.html`, `sitemap.xml`, `robots.txt`, `CNAME`, `favicon.svg`)
лежат в репозитории — GitHub Pages отдаёт их напрямую.

## Сборка

```bash
python3 build.py
```

Правим `content.py` (тексты, таблицы, FAQ) или `build.py` (вёрстка) → запускаем сборку →
коммитим изменившиеся HTML.

Локальный просмотр:

```bash
python3 -m http.server 4328
```

## Конверсия

Три канала на каждой странице:

1. **Звонок** — телефон в шапке, в CTA, в подвале и в мобильной липкой панели.
2. **Почта** — формы собирают поля и открывают письмо на `i.kim@lukoil-oil.uz`
   с готовой темой и телом (без бэкенда). Прямые `mailto:`-ссылки дублируют форму.
3. **Обратный звонок** — модалка, тоже уходит письмом.

Телефон помечен мелкой припиской «номер не активный с июня 2017» — рабочий канал почта.

## SEO

- Уникальные `title` (≤70) и `description` (≤165) на каждой странице.
- `canonical`, Open Graph, `robots: max-image-preview:large`.
- JSON-LD: `Organization`, `LocalBusiness`, `Product`, `FAQPage`, `BreadcrumbList`,
  `ItemList`, `ContactPage`.
- `sitemap.xml`, `robots.txt`, хлебные крошки, один `h1` на страницу, `alt` у всех фото.

## Скорость

- Ни одного внешнего запроса: шрифты, стили, скрипты и фото — со своего домена.
- Главная: 6 запросов, ~200 КБ. Шрифт — переменный woff2, кириллица 22 КБ.
- Фото в webp с jpg-фолбэком, `width`/`height` проставлены, всё кроме LCP — `loading="lazy"`.
- LCP-изображение и шрифт кириллицы — в `preload`.
